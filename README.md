
# Sistema de tickets de soporte IT

Aplicación web desarrollada con Python, Flask y SQLite para registrar, asignar y dar seguimiento a incidencias informáticas en un entorno de manufactura ficticio.

Este proyecto personal tiene como objetivo practicar desarrollo web, administración de bases de datos y documentación de incidentes de soporte IT.

## Funcionalidades

- Registrar tickets de soporte con descripción, categoría y prioridad.
- Consultar y buscar incidencias registradas.
- Asignar responsables y actualizar el estado de los tickets.
- Documentar acciones de diagnóstico y notas de seguimiento.
- Consultar el historial de actualizaciones de cada incidente.
- Almacenar los registros mediante SQLite.
- Utilizar una interfaz web desarrollada con HTML y CSS.

## Tecnologías utilizadas

- Python
- Flask
- SQLite y SQL
- HTML
- CSS
- Git y GitHub

## Vista general

La aplicación simula el flujo de trabajo de una mesa de ayuda informática: desde el registro de una incidencia hasta la documentación de su seguimiento y resolución.

Los tickets y los usuarios utilizados en las pruebas son ficticios.
