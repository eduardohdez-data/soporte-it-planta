
# Guía de capturas de pantalla

Esta guía explica cómo ejecutar la aplicación y preparar capturas para documentar el proyecto en GitHub.

## 1. Ejecutar la aplicación

Abre una terminal en la carpeta que contiene `app.py` y ejecuta:

```cmd
.venv\Scripts\activate.bat
python app.py
```

Abre http://127.0.0.1:5000 en el navegador.

## 2. Captura del panel principal

Abre la página principal y verifica que se muestren los tickets de demostración.

Guarda una captura con el nombre:

`panel.png`

## 3. Captura del detalle de un ticket

Abre un ticket y muestra su descripción, prioridad, responsable y estado.

Guarda una captura con el nombre:

`detalle-ticket.png`

## 4. Captura del historial de seguimiento

En la página del ticket, muestra las notas y las actualizaciones realizadas durante la atención del incidente.

Guarda una captura con el nombre:

`historial-ticket.png`

## 5. Buenas prácticas

- Utiliza únicamente datos ficticios.
- No muestres contraseñas ni información personal.
- Procura que el texto de las capturas sea legible.
- No presentes los incidentes simulados como problemas reales de una empresa.

Las capturas sirven para documentar el funcionamiento del proyecto. No sustituyen al código fuente ni a las instrucciones de instalación.
